Super Admin Sign In

Development team access only — not a barangay/LGU role.

Prototype note: any non-empty passphrase works until this is wired to a real restricted-access mechanism (e.g. a separate Firebase custom-claim check).

Create Barangay / LGU Administrator Account

Use Case: "Create Barangay/LGU Administrator Account." This is the only account type the Super Admin creates directly — Electrician and Finance Officer accounts are provisioned by that Administrator afterward, in User Management.

Other Super Admin Functions

Per the Use Case Diagram, the Super Admin also configures initial system setup, database/backend settings, deploys firmware to monitoring nodes, monitors overall system health, and can access all modules for QA/testing. These are development-team operational tasks (Firebase console, ESP32 firmware flashing, etc.) rather than barangay-facing dashboard features, so they're intentionally left out of this web UI — flag it if you want any of these built out as an actual page.
